# 🎓 Student Grade Management System

Talabalar baholarini boshqaruvchi C# Console dasturi.
Talabalarni qo'shish, baholarini saqlash, o'rtacha bahoni
hisoblash va eng yaxshi talabalarni aniqlash mumkin.

---

## 📋 Imkoniyatlari

- ✅ Talaba qo'shish
- ✅ Talabalarni ko'rish
- ✅ Baho qo'shish
- ✅ O'rtacha bahoni hisoblash
- ✅ Eng yaxshi talabani topish
- ✅ Failed studentlar
- ✅ Talaba qidirish
